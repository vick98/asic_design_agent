# glue

模块类型：group

把顶层样本接到 alu。

## 2. 模块功能

例化 alu，不新增运算。

## 3. 模块接口

| 名字 | 方向 | 位宽 | 时钟域 | 说明 | 位宽依据 |
|---|---|---|---|---|---|
| i_a | input | 8 | clk | 加数 | 与 alu 相同 |
| i_b | input | 8 | clk | 加数 | 与 alu 相同 |
| o_y | output | 8 | clk | 和 | 与 alu 相同 |

## 4. 模块处理流程

组合接通，时序在 alu 内。

## 5. 组成模块

只包含 alu。

## 6. 模块连接关系

无内部组成模块。

| 源 | 目标 | 位宽 | 时钟域 | 说明 |
|---|---|---|---|---|
| i_a | alu.i_a | 8 | clk | 直连 |
| i_b | alu.i_b | 8 | clk | 直连 |
| alu.o_y | o_y | 8 | clk | 直连 |
