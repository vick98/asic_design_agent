# 编码

`spec2rtl` 与 `sys_spec2rtl` 的可综合 RTL 写法。功能以模块规格书与交付 IR 为准，本文只管代码形态；写完逐条过 §8 的自查清单。

## 文件头

每个 `.v`/`.sv` 以块注释文件头开头，包含：Filename（与实际文件名一致，含后缀）、Author、是否可综合、版本历史（VERSION/DATE/AUTHOR/DESCRIPTION）、一句话功能描述。文件头不放例化示例：例化由 agent 按模块规格书端口表与 `rules/pubip.md` 端口表执行，不靠头注释里的示例。

## 命名

- 端口前缀：输入 `i_`，输出 `o_`；内部寄存器 `reg_`，内部组合 `wir_`；时钟与复位是豁免名：`clk_in`、`rst_n`
- 模块直连且中间没有胶合时，中间信号名 `wir_<源模块>2<宿模块>_<信号>`，`<信号>` 为源端口去掉方向前缀的基础名
- 每行只声明一个变量；代码 token 与分隔线一律半角，中文注释允许全角标点

## 结构顺序

文件头 → 参数声明 → 端口声明 → localparam → 内部信号声明 → 例化 → 时序逻辑 → 组合逻辑。

- 端口声明的方向与位宽按列对齐，逗号对齐，一项一行，每个端口带注释
- 所有内部信号在内部信号声明区内声明，逻辑实现区不再出现声明
- 子功能块用分隔注释 `//----------- 子功能名称 ------------` 标出
- 数据通路与控制器分开写

## always 拆分与赋值

- 可综合代码用 `logic`；时序用 `always_ff`，复杂组合用 `always_comb`
- 处理条件不同的寄存器拆成独立 `always` 块，不合并；一个 `always` 只做一类事，不把状态转移和数据通路写进同一块
- 不给同一信号自赋值：保持值场景（如 `a <= a;`）直接删除该赋值
- `case` 必须有放在最后的 `default`，即使已覆盖所有取值
- 同一表达式多处使用时先赋给一个变量再引用
- 单行语句不加 `begin end`，多行语句才加
- 对外控制信号复位后不得为 X

## 三档常见写法

- 状态机（FSM）：一段时序块只寄存状态（复位到 IDLE），一段组合块决定下一状态与输出；状态用 localparam 枚举命名，不写裸数字；输出不允许从状态位直接毛刺解码，需要时寄存一拍
- 计数器：时序块里使能有效时加一，复位清零；到顶后保持还是回卷必须在规格书里写明；比较用 `==` 计数值参数化，不写魔法数
- 打拍：只把数据或控制延后固定拍，不在打拍块里做运算；打拍数与规格书拍数一致，多级打拍的各级命名体现级数

## 例化与公共模块

- 例化按数据流顺序排列：单实例 `<模块名>_inst`，多实例 `<模块名>_<序号>_inst`；规格书指定实例名的从其指定
- 端口连接全部显式写出，不省略端口名
- 用到公共模块（见 `rules/pubip.md`）时参数与端口写全，未用输入接常量并注明原因

## 跨时钟域

端口表与连接表的时钟域列（列定义见 `rules/spec.md`）标出两个以上时钟域时，跨域信号按本节写；同一时钟域内的信号不受本节约束，不归属某域、填 `—` 的信号不用同步器。信号属于哪个域以规格书为准，不在 RTL 里自行改判。

- 单比特控制：源域先寄存一拍再输出，目标域用两级同步器同步（两个 `always_ff` 级联，第一级不打逻辑、不带组合），同步器输出只作控制使用
- 多比特控制：用握手或保持寄存器。握手是源域置 `req` 并保持数据，目标域同步 `req` 后采样并回 `ack`，`ack` 回来前源域不换数据；保持寄存器是数据在源域稳定到整体搬完，目标域只同步单比特有效指示再采样。**不得**把多比特总线逐位打两拍当同步器用
- 数据流：用异步 FIFO 搬运，读写指针各留在自己的时钟域，空满指示用格雷码跨域；FIFO 必须用公共单元，不自写
- 复位：跨域模块用异步复位同步释放——复位异步置位，释放经两级同步器，每个时钟域各自同步自己那一份复位；同步器与 FIFO 的复位释放按公共单元的端口接，不在外面另加一级

两级同步器与异步 FIFO 从 `rules/pubip.md` 的跨时钟域公共单元取（`pubip_cdc_sync`、`pubip_async_fifo`，都已登记）；复位同步器还没有公共单元，需要时按 §例化与公共模块 提报，不自行新写。跨域信号在规格书说明列点明处理方式，RTL 里每级同步器单独成块，命名体现时钟域与级数。

## 自查清单

1. 文件头 Filename 与文件名一致
2. 结构顺序完整；内部信号都在声明区
3. 命名前缀正确；直连命名符合 `wir_<源>2<宿>_<信号>`
4. 每个 `case` 有 `default`；无自赋值；无裸 `$display` 调试残留
5. 复位后对外控制信号非 X；无 latch 意外推断（组合块所有分支都有赋值）
6. 端口与交付 IR 一致；不一致项已列入输出小结
7. 跨域信号按 §跨时钟域 处理：多比特未逐位打两拍；两级同步器、异步 FIFO 取自 `rules/pubip.md` 已登记单元，复位同步器按 §例化与公共模块 提报
