# 定点

格式写作 `<总位宽, 整数位宽, 符号>`。`t` 是有符号补码，`u` 是无符号。公式在这里定义，数字由工具计算：

```text
python3 script/framework.py fx mul  '<W,I,t>' '<W,I,t>'
python3 script/framework.py fx cmul '<W,I,t>' '<W,I,t>'
python3 script/framework.py fx add  '<W,I,u>' '<W,I,u>'
python3 script/framework.py fx shift '<W,I,t>' --n 2 --shrink
python3 script/framework.py fx finish '10,2,t' --dest '8,2,t' --n 2
python3 script/framework.py fx sat '<W,I,t>' [--symmetric]
python3 script/framework.py fx obs16 '<W,I,t>'
python3 script/framework.py fx pack --widths 8 4 4
python3 script/framework.py fx addr --depths 128 64 --bits 8
```

运算规则：

- 整数位 `I` 不含符号位。`t` 须 `W ≥ I+1`，`u` 须 `W ≥ I`，且 `I ≥ 0`。
- 无符号乘：`W = W1+W2`，`I = I1+I2`，符号 `u`。
- 有符号乘：`W = W1+W2-1`，`I = I1+I2`，符号 `t`。一端无符号时先 `lift` 再按有符号乘。
- `lift` 把 `u` 变成 `<W+1,I,t>`，`t` 不变。
- 复数乘：两端都是 `t`，否则先 `lift`。`W = W1+W2`，`I = I1+I2+1`。
- 加：两端皆 `u` 时小数位取较大者，整数位取较大者再加 1，符号仍为 `u`；一端 `u` 一端 `t` 时先把 `u` 端 `lift`，再按有符号加。有符号加：`f = max(f1,f2)`，`I = max(I1,I2) + 1`，`W = I + f + 1`，符号 `t`。
- 减：两端都是 `u` 时结果为 `<1+maxI+maxF, maxI, t>`。其余与加相同，先 `lift` 再按有符号加的位宽。
- 算术右移且缩短容器：`W` 和 `I` 同减移位数。不缩短时格式元组不变。`I < n` 时缩短非法。
- 舍入右移：`trunc` 是算术右移；`half_up` 是先加半个 LSB 再算术右移；`even` 是半值向偶数靠。
- 收尾：`finish <W,I,t> --dest <W,I,t> --n N` 是右移 N 位 half-up 后经对称饱和落入目标容器的一步运算。闭合条件：符号一致且 `f_dst = f_src − N`；饱和允许 `I_dst < I_src`（峰值余量靠实测），目标界随结果返回。产物里收尾推导行写 `finish <W,I,t> >> N half-up + sat -> <W,I,t>` 加戳记，闸门按同式复算。
- 饱和，有符号且不对称：正界 `2^(W-1)-1`，负界 `-2^(W-1)`。对称时负界为 `1-2^(W-1)`。无符号为 `0 … 2^W-1`。
- **对称运算约束（2026-10-18 起，开发者裁定）**：有符号数的补码负界比正界绝对值大 1（如 8bit 为 −128…127），因此有符号数据的**输入有效域排除负最小值**——`−2^(W-1)` 是无效数，激励生成、角点与极限用例一律落在 `[−(2^(W-1)−1), +(2^(W-1)−1)]`；**截位/饱和一律对称**（`fx sat '<W,I,t>' --symmetric`，负界 `1−2^(W-1)`）。fx 的格式与容器推导不变（容器仍覆盖全数学域），对称域只约束输入数据与激励：设计文档的边界点若写 `−2^(W-1)`，须注明那是容器数学界、非有效输入；TB 参考模型与激励域按本条构造，违例输入判 TB 错误而非 DUT 错误。
- 观测 16 bit：总位宽不超过 16 时左对齐、低位补 0；超过 16 时算术右移 `W-16`。这条只覆盖 16 位观测口；更宽的观测字与存储字段的打包不走这条，各自由裁决承载，用已有的移位、饱和算式加戳记表达。"左对齐"只称呼 16 位口的低位补 0，不用来称呼同 `f` 落位（低位对齐加符号扩展）。

饱和之后的目标格式是设计选择，工具不替人选定。人定了目标，再用 `shift` 和 `sat` 算移多少、界是多少。

定点格式出现时，只有三种写法能过 `fx-bare`，各举一例：

1. 算式加 `stamp:`：`<24,3,t> ** <12,1,t> → <36,5,t>  stamp: c09a6a41881b`。算式含四则、`shift`、`finish`、`lift`、`obs16`、`sat`、`sac`；戳记在本行或下一行，并按就近归属——一行写多条算式时，每条只认它结束之后、下一条算式之前的第一枚戳记。
2. 有名字的节点：`` `n_corr` <24,3,t> ``。
3. 端口位宽带格式：`12（<12,1,t>）`，数字须等于格式的总位宽（同时受 D4 约束）。

只写 `<24,3,t>` 而没有算式、命名节点或戳记，报 `fx-bare`；别处有戳记不算豁免。

文档里的 `→ <W,I,t>` 必须和工具再算的结果一致，否则 `tick` 不会让它完成（闸门未过），停在"进行中"。
